# Artwork and screenshots

`harness-bridge-cover.jpg` is an original illustration generated for this project with Seedream 5 Pro (`doubao-seedream-5-0-pro-260628`), at 1536 × 768 pixels. It is a conceptual illustration, not a screenshot of DSH or Claude Code.

The prompt describes two abstract terminal workspaces connected by an architectural bridge: cool blue task cards for planning, warm amber code blocks for execution, and a mint return path through a verification checkpoint. It requests a dark navy background, restrained isometric geometry, no text and no branded logos.

The artwork is distributed with this repository under its [MIT license](../../LICENSE). No image-generation credentials or temporary provider URLs are included.

## Real interaction screenshots

The five PNG files were captured from an isolated US DSH Web instance using Claude Code `2.1.325` through the operator's Grok proxy. They show the native language/settings form, headless tool output and translated report, the running CC process attached through DSH's terminal, and DSH proposal application with the original repository's source diff.

The captures exclude the browser address bar and unrelated sessions. The headless report was cropped to its chat viewport. No tool output, model response, review state or source diff was synthesized or retouched. The tmux capture is a read-only follow-up after the edit shown in the review capture.
